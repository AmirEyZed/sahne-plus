## Sahne+ 1.3.4

**Version:** 1.3.4 · **Release date:** 2026-09-22

### What's new
- **StreamElements tips.** If you also take tips through a StreamElements tipping page, paste your StreamElements JWT token in Settings (StreamElements dashboard → Account → Channels → Show secrets). Those tips enter the same queue as KickBot donations and use the same files and tiers. The token is stored encrypted, never shown or logged, and «قطع اتصال و حذف توکن» removes it. Set the tipping currency to USD for toman conversion; other currencies are shown as amount + currency code.
- Verify this installer: `gh attestation verify .\Sahne-Plus-Setup-1.3.4.exe --repo AmirEyZed/sahne-plus`

### How to update
Sahne+ 1.3.1 and later show a notice inside the app: click **آپدیت**. From 1.3.0 or older, install this file manually once.
