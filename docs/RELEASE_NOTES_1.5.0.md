## Sahne+ 1.5.0

**Version:** 1.5.0 · **Release date:** 2026-10-18

### What's new
- **New look: «Mint stage».** The controller window moves from the dark theme to a light mint glass look — frosted panels, deep-green ink, pill buttons, the SAHNE mark as a quiet pattern. Pages turn in 3D, cards rise in with a stagger and tilt under the pointer, the nav capsule springs and the connection dots pulse. All motion is switched off when Windows' «reduce motion» is on. Nothing changes in what the app does: files, tiers, alerts, KickBot, Kick, StreamElements and the Browser Source behave exactly as in 1.4.2.
- **Layout and readability.** Card rows fill every window width from 1000 to 1900 px without empty holes; text contrast on every page was measured from rendered pixels and now meets WCAG AA; every control keeps a visible focus ring; native widgets stay light under Windows dark mode.
- Includes **1.4.2** (released a few hours earlier): Kick subs and gift subs work again after Kick rotated the key of its public chat feed on 2026-10-13, and the app now fetches a new key by itself when that happens again. If you are on 1.4.1 or older, this is the update that brings your Kick alerts back.
- Verify this installer: `gh attestation verify .\Sahne-Plus-Setup-1.5.0.exe --repo AmirEyZed/sahne-plus`

### How to update
Sahne+ 1.3.1 and later show a notice inside the app: click **آپدیت**. From 1.3.0 or older, install this file manually once.
