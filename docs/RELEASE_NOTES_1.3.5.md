## Sahne+ 1.3.5

**Version:** 1.3.5 · **Release date:** 2026-09-22

### What's new
- **StreamElements tips in other currencies now play.** A tip in euro, pound, dirham, lira and other common currencies is converted to toman with the day's rate (from the same rate source as the dollar), uses the same tiers as dollar tips, and the card shows both. In 1.3.4 such tips only showed the amount and no file played.
- Verify this installer: `gh attestation verify .\Sahne-Plus-Setup-1.3.5.exe --repo AmirEyZed/sahne-plus`

### How to update
Sahne+ 1.3.1 and later show a notice inside the app: click **آپدیت**. From 1.3.0 or older, install this file manually once.
